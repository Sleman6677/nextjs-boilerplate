# Serag Lashes · سراج لاشز

متجر إلكتروني للرموش، مبني بـ Next.js 16 وTailwind CSS v4 وSupabase، بثلاث لغات: العربية والعبرية (من اليمين لليسار) والإنجليزية. مصمَّم للموبايل أولًا.

## ما يوجد في الموقع

**للزبونات**
- صفحة رئيسية للمتجر: المجموعات الثلاث، وصل حديثًا، الأكثر مبيعًا، التخفيضات، بطاقات الهدية، وأزرار إنستغرام وواتساب وتيك توك.
- صفحة لكل منتج:
  - صور متعددة، السعر قبل التخفيض وبعده، والخيارات (مثل الطول) قبل الإضافة للسلة.
  - الكمية، حالة المخزون (متوفر / كمية قليلة / نفد)، والمفضلة.
  - التقييمات، ومنتجات مرافقة بسعر خاص، ومنتجات مشابهة.
- «أبلغيني عند توفر المنتج»: تصل رسالة تلقائيًا عند عودة المنتج للمخزون.
- السلة:
  - تعديل الكمية، كود خصم، بطاقة هدية، استعمال النقاط، ملاحظة على الطلب.
  - منطقة التوصيل وسعرها، واقتراحات «أضيفي بسعر خاص».
- إتمام الطلب بدون تسجيل دخول: العضوية تُنشأ تلقائيًا برقم الهاتف مع أول طلب.
- الدفع: بطاقة ائتمان (אשראי)، Apple Pay، Bit، أو نقدًا عند الاستلام.
- الحساب (الدخول برمز SMS على الهاتف):
  - الطلبات الحالية والسابقة مع حالتها، ورقم التتبع، والفاتورة، وزر «إعادة الطلب».
  - النقاط وتاريخ انتهائها، الكوبونات، المفضلة، العناوين، البيانات وتاريخ الميلاد، وتقييم المشتريات.
- حالة الطلب: تم الاستلام ← قيد التجهيز ← تم الشحن ← في الطريق ← تم التسليم، مع رسالة SMS عند كل تغيير.

**لوحة التحكم `/admin`** (بالعربية، لصاحب المتجر والموظفين حسب صلاحياتهم)
- **نظرة عامة والمبيعات:**
  - اليوم والأسبوع والشهر، متوسط الطلب، رسم المبيعات اليومية.
  - الأكثر والأقل مبيعًا، والمنتجات القريبة من النفاد أو النافدة.
- **الطلبات:**
  - بحث وتصفية، وتغيير الحالة خطوة بخطوة، وتأكيد الدفع، والإلغاء.
  - رقم التتبع وشركة الشحن، وإصدار فاتورة PayPlus للطلبات النقدية.
  - مصدر الطلب، ومن عدّل ماذا.
- **المنتجات والمخزون:**
  - صور، خيارات بكمية خاصة لكل خيار، سعر تخفيض بتواريخ، منتجات مرافقة بسعر خاص، وبطاقات الهدية.
  - تعديل سريع للكمية، وتنبيه بالرسائل عند انخفاضها.
- **المجموعات والتقييمات** (نشر / إخفاء / حذف).
- **العروض:** خصم تلقائي على منتج أو مجموعة، نسبة أو مبلغ، لفترة محددة أو عند شراء كمية.
- **الكوبونات:**
  - خيارات الكوبون: منتجات أو مجموعات محددة، استثناء المنتجات المخفّضة، مصدر (مؤثرة/حملة)، حد أدنى، تواريخ، عدد مرات.
  - إحصائيات لكل كوبون: من استعمله، كم مرة، المبيعات، الخصومات، التاريخ والوقت.
- **بطاقات الهدية:** الحالة (غير مستعملة / جزئيًا / بالكامل / منتهية)، الرصيد، من اشتراها، وأين استُعملت، وإصدار يدوي.
- **الرسائل:**
  - نصوص كل الرسائل بثلاث لغات، وسجل الإرسال.
  - رسائل تسويقية لجمهور محدد، مع فصل الرسائل التسويقية عن رسائل الطلبات.
- **السلات المتروكة:** تذكير تلقائي، أو يدوي مع كوبون.
- **الزبائن:** بحث بالاسم أو الهاتف، وصفحة لكل زبونة فيها الطلبات والمنتجات والكوبونات وبطاقات الهدية والنقاط، مع إمكانية تعديل النقاط وإنشاء كوبون خاص.
- **مصادر الطلبات:** الموقع، Instagram، TikTok، حملة، كود مؤثرة.
- **الشحن:** مناطق وأسعار، استلام ذاتي، حد توصيل مجاني لكل منطقة، وشركات شحن مع روابط تتبع.
- **الإعدادات:** النقاط وانتهاؤها، بطاقات الهدية، خصم عيد الميلاد، السلات المتروكة، شريط الإعلان، حسابات التواصل، ونوع الفاتورة.
- **الطاقم:** حسابات وصلاحيات (الطلبات، المنتجات، الزبائن، التسويق، التقارير، الإعدادات، الطاقم)، وسجل بكل تعديل.
- **تصدير CSV** للطلبات والزبائن والمنتجات.

## قواعد الأسعار

- سعر المنتج = الأقل بين سعره، وسعر التخفيض، وأفضل عرض تلقائي. العروض لا تجتمع مع بعضها.
- فوق ذلك **خصم واحد فقط**: كوبون، أو خصم الطلب الأول، أو كوبون عيد الميلاد. الكوبون يحلّ محل خصم الطلب الأول.
- التوصيل المجاني يُحسب بعد الخصم، ولكل منطقة حد خاص اختياري.
- النقاط:
  - تُكسب نسبة من المبلغ المدفوع فعلًا للمنتجات، وتُضاف عند التسليم.
  - يمكن أن تنتهي بعد مدة تُحدَّد في الإعدادات.
  - لا تدفع ثمن التوصيل ولا بطاقات الهدية.
- بطاقة الهدية:
  - تحصل على زيادة (افتراضيًا 10٪: تدفع 200 ₪ فتحصل على 220 ₪).
  - تدفع ثمن المنتجات والتوصيل، ويبقى الرصيد المتبقي للمرة القادمة.
  - لا تُشترى بها بطاقة هدية أخرى.
- الأسعار تُحسب دائمًا على الخادم.

## خطوات التشغيل (مرة واحدة)

### 1. قاعدة البيانات

1. في Vercel: المشروع ← **Storage** ← **Create Database** ← **Supabase**، ثم ربطها بالمشروع. المتغيرات (`POSTGRES_URL`، `NEXT_PUBLIC_SUPABASE_URL`، `NEXT_PUBLIC_SUPABASE_ANON_KEY`، `SUPABASE_SERVICE_ROLE_KEY`) تُضاف تلقائيًا.
2. في Supabase ← **SQL Editor**: تشغيل الملفين **بالترتيب** (لصق كل ملف كاملًا ثم **Run**):
   1. `supabase/migrations/20261105000000_shop.sql`
   2. `supabase/migrations/20261106000000_store.sql`

   تشغيلهما مرة ثانية آمن.

### 2. تسجيل الدخول برمز SMS (019 SMS)

1. فتح حساب في **019 SMS** (docs.019sms.co.il)، ثم إنشاء رمز API من **Settings ← Token API**، وتسجيل اسم المرسِل (حتى 11 حرفًا إنجليزيًا، مثل `SeragLashes`).
   - **يجب التأكد معهم من دعم الرسائل بالعربية والعبرية (Unicode)**، فتوثيقهم لا يذكر ذلك.
2. في Supabase ← **Authentication ← Sign In / Providers ← Phone**: تفعيل الدخول بالهاتف.
3. في Supabase ← **Authentication ← Hooks**: إضافة **Send SMS hook** من نوع **HTTP**:
   - الرابط: `https://<دومين الموقع>/api/auth/sms-hook`
   - إنشاء السر (Secret) ونسخه.
4. في Supabase ← **Authentication ← Rate Limits**: ضبط حدود إرسال الرسائل. يُنصح أيضًا بتفعيل CAPTCHA لتقليل كلفة الرسائل.

### 3. متغيرات Vercel

في Vercel ← **Settings ← Environment Variables**:

| المتغير | القيمة |
|---|---|
| `SUPABASE_SMS_HOOK_SECRET` | السر من خطوة الـ Hook (يبدأ بـ `v1,whsec_`) |
| `SMS019_USERNAME`، `SMS019_TOKEN` | اسم المستخدم ورمز API من 019 |
| `SMS_SENDER` | اسم المرسِل المسجّل، مثل `SeragLashes` |
| `ADMIN_PHONES` | رقم هاتف صاحب المتجر (أو أكثر، تفصل بينها فاصلة) |
| `ADMIN_EMAILS` | (اختياري) دخول صاحب المتجر بالبريد |
| `PAYPLUS_API_KEY`، `PAYPLUS_SECRET_KEY`، `PAYPLUS_PAYMENT_PAGE_UID` | من لوحة PayPlus |
| `PAYPLUS_ENV` | `staging` للتجربة، ويُحذف عند التشغيل الحقيقي |
| `PAYPLUS_METHODS` | الطرق المفعّلة في صفحة PayPlus، افتراضيًا `card,bit,apple_pay` |
| `CRON_SECRET` | أي نص عشوائي طويل؛ لتشغيل المهمة اليومية |
| `NEXT_PUBLIC_SITE_URL` | (اختياري) الدومين الرسمي، مثل `https://seraglashes.co.il`؛ الروابط في الرسائل تعتمد عليه |
| `NEXT_PUBLIC_GA_ID` | (اختياري) Google Analytics 4، مثل `G-XXXXXXX` |
| `NEXT_PUBLIC_META_PIXEL_ID` | (اختياري) Meta Pixel |

ثم **Redeploy**.

> المفاتيح السرية مكانها إعدادات Vercel فقط، لا في الكود ولا في أي رسالة.

### 4. الدفع والفواتير (PayPlus)

- بعد الدفع يرسل PayPlus إشعارًا موقَّعًا إلى `/api/payplus/callback`، فيصبح الطلب «مدفوعًا»، وتصل للزبونة رسالة التأكيد، وتُصدَر بطاقات الهدية إن وُجدت.
- **الفواتير:**
  - للدفع الإلكتروني: تفعيل خدمة **Invoice+** في صفحة الدفع عند PayPlus، فتُصدر الفاتورة تلقائيًا ويُحفظ رقمها ورابطها في الطلب.
  - للطلبات النقدية: زر «إصدار فاتورة» في صفحة الطلب في اللوحة. نوع المستند (חשבונית מס קבלה / קבלה) يُختار من الإعدادات.
  - يُفضَّل تجربة ذلك أولًا على بيئة staging.
- بطاقة اختبار من توثيق PayPlus لبيئة staging: `5326-1402-8077-9844`، تاريخ `05/30`، CVV `000`.

### 5. المهمة اليومية

`vercel.json` يشغّل `/api/cron/daily` يوميًا الساعة 07:00 UTC (10:00 بتوقيت البلاد). المهمة:
- تلغي الطلبات غير المدفوعة وتعيد كميتها للمخزون.
- تُنهي النقاط المنتهية.
- ترسل خصم عيد الميلاد.
- ترسل تذكير السلات المتروكة.

باقة Vercel المجانية تسمح بتشغيل مرة يوميًا؛ للتذكير بعد ساعات قليلة يلزم Pro مع جدول كل ساعة.

## الرسائل والقانون

- رسائل الطلبات تصل لكل زبونة.
- رسائل العروض (عيد الميلاد، السلة المتروكة، الرسائل التسويقية، خصم على منتج في المفضلة) تصل فقط لمن وافقت عليها.
  - الموافقة: مربع غير محدَّد مسبقًا عند الدفع، أو من الحساب.
  - كل رسالة تسويقية تبدأ بكلمة «פרסומת» وتنتهي برابط إلغاء الاشتراك، وفق חוק התקשורת (סעיף 30א). يُفضَّل مراجعة ذلك مع محامٍ.
- بدون حساب 019 تُحفظ الرسائل في اللوحة «بانتظار الإرسال»، ويمكن إرسالها يدويًا بالواتساب. **تسجيل الدخول بالهاتف لا يعمل بدون الحساب**؛ الموظفون يستطيعون الدخول بالبريد.

## المصادر والإعلانات

- رابط لمؤثرة أو مسوقة: `https://<الدومين>/ar?ref=noor`، فكل طلب بعده خلال 30 يومًا يُحسب لها.
- حملة إعلانية: `?utm_source=instagram&utm_campaign=eid`.
- كوبون له «مصدر»: يُحسب له كل طلب استعمله.
- Google Analytics وMeta Pixel يستقبلان أحداث مشاهدة المنتج، والإضافة للسلة، وبدء الدفع، والشراء.

## الأمان والنسخ الاحتياطي

- قاعدة البيانات تُقرأ من الخادم فقط. كل الجداول مقفلة بـ RLS أمام واجهة Supabase العامة.
- اللوحة محمية بتسجيل الدخول والصلاحيات، وتُفحص الصلاحية في كل عملية على الخادم.
- ترويسات أمان (HSTS، منع التضمين…) مضبوطة في `next.config.ts`. HTTPS يوفّره Vercel.
- النسخ الاحتياطي: Supabase يأخذ نسخة يومية في الباقة Pro، ويمكن الاسترجاع من لوحته. وللاحتفاظ بنسخة محلية: الإعدادات ← تصدير CSV.
- SEO: `sitemap.xml` بالروابط الثلاث لكل صفحة ومنتج، و`robots.txt`، وبيانات المنتج المنظّمة (JSON-LD).
